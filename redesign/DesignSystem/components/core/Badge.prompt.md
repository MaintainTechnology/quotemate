Square mono-uppercase chip — trust signals, pilot status, metadata. Never rounded.

```jsx
<Badge icon={<img src="assets/icons/au-flag.svg" alt="Australia" style={{height:12}}/>}>Built for Australian tradies</Badge>
<Badge tone="accent">Electrical pilot · NSW</Badge>
<Badge tone="solid">Most popular</Badge>
```

- **Tones:** `neutral` (hairline, dim) · `accent` (yellow-tinted border + wash) · `solid` (yellow fill, dark ink).
- Keep labels to a few uppercase words. Use real flag/partner SVGs for `icon`, not emoji.
