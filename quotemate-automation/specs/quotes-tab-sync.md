# Quotes tab shows every tenant quote across all trades, with timely refresh

## Goal

Every quote or job the signed-in tradie generates — via the SMS/voice pipeline or any platform trade tab (electrical, plumbing, roofing, painting, commercial-paint, solar, aircon) — is visible on the dashboard **Quotes tab** (cross-trade workspace view) within one tab-switch, regardless of status (draft / in review / inspection / deposit). Why: today the workspace Quotes view shows only the newest 20 `quotes`-table rows; measure-tool jobs (roofing/solar/painting/commercial-paint) render only inside their own trade hub, aircon persists nothing at all, and nothing refetches after mount — so trade-tab work looks "lost".

## Role

Principal engineer for this repo. Reason before acting; act with tools; minimal diffs matching the style of each touched file; parallel independent tool calls; never guess a parameter — read the file or run the check first. This spec is the contract for /build and /review — do not re-engineer it mid-run.

## Constraints

- **Out of scope (do not build; documented for the user):**
  - **Signage:** generates org-scoped compliance assessments, not quotes — its tables have no `tenant_id` and no price artifact; surfacing it in a tenant Quotes tab needs a product decision, not a query.
  - **Estimator (beta)** electrical take-offs (not in the requested trade list; priced BOMs dead-end by design today).
  - **NULL-tenant orphan quotes** (shared dev number / unmatched Vapi assistant) — accepted, documented debt (CLAUDE.md); cannot be shown in a tenant-scoped tab.
  - **Solar `quotes.status` stuck at `'draft'`** after customer release — a status-accuracy bug, not a visibility one (solar quotes do appear); log as a finding only.
  - The **Overview tab** work (recent-activity merge, chats error states) — owned by `specs/dashboard-overview-quotes-sync.md`.
  - Server pagination beyond the 100 cap.
- No new dependencies, no schema migrations (144 already exists — verify it is applied before relying on it; if the prod table is missing, run `scripts/run-migration-144.mjs`), no `page.tsx` refactor beyond the named sections, no changes to `/api/tenant/trade-jobs` response shape other than the additive aircon rows.
- The aircon insert must never fail or delay the recommendation response beyond the insert itself; the route keeps returning 200 with the recommendation when the insert errors.
- Match surrounding code style/comment conventions; Australian English; no emoji. Delete any scratch files created during the run.
