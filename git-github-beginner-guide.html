Set up Git and GitHub, step by step.

Git keeps a full history of your work. GitHub keeps a safe copy of it online. This guide installs both, connects them, and proves the whole thing works, in plain English, one small step at a time.

Part 03 I use a Mac Install Git with the built-in tools on macOS. Part 04 I use Windows Install Git for Windows with a simple installer.

Part 01·Start here

What are Git and GitHub?

They sound similar, and they work together, but they are two different things. Here is the simplest honest version.

Git · on your computer

The tracker

Git is a free program that runs on your computer. It watches the files in a project folder and keeps a full history of every change, like a very powerful undo button. You can always go back to an earlier version of your work.

GitHub · on the internet

The backup

GitHub is a website (github.com) that stores an online copy of your Git projects. If your computer breaks, your work is safe. It is also how you share projects and team up with other people.

Part 02·Everyone does this first

Create your GitHub account

Mac or Windows, the account works the same. It is free and takes about five minutes.

01

Go to github.com

Open your web browser and go to github.com, then click the Sign up button in the top right corner.

02

Choose your details

Enter your email address, then follow the prompts to pick a password and a username.

Tip

Your username will be public. Pick something you are happy for others to see.

03

Confirm your email

GitHub sends a code to your email address. Type it in to confirm the account.

04

Pick the free plan

If GitHub asks questions like how many people you will work with, pick any answer or skip. When it asks about plans, choose Free.

Done

You now have a GitHub account. Keep your username and password somewhere safe.

Part 04·Skip this if you use a Mac

Windows

Install Git on Windows

01

Download Git for Windows

  1. Open your web browser and go to git-scm.com/download/win.
  2. The download usually starts on its own. If not, click 64-bit Git for Windows Setup.
  3. When it finishes, open the downloaded file. It will be named something like Git-2.xx.x-64-bit.exe.
02

Run the installer, keep the defaults

  1. If Windows asks whether to allow the app to make changes, click Yes.
  2. The installer shows many screens of options. You do not need to change anything. Click Next on every screen, then Install.
  3. When it finishes, click Finish.
Tip

The default options are sensible, and they include a helper that makes signing in to GitHub easy later.

03

Open Git Bash

The installer added a program called Git Bash. That is the window where you type Git commands.

Part 05·Everyone does this part · About 10 minutes

Connect Git to GitHub and prove it works

The best test of your setup is one tiny project, start to finish. One quick word first: a repository (or repo) is just Git's word for a project folder that Git is tracking.

01

Create a repository on GitHub

  1. Go to github.com and sign in.
  2. Click the + button in the top right corner, then New repository.
  3. In Repository name, type hello-world.
  4. Tick the box Add a README file.
  5. Click the green Create repository button.
02

Copy the repository's address

  1. On your new repository's page, click the green Code button.
  2. Make sure the HTTPS tab is selected.
  3. Click the copy icon next to the address. It looks like https://github.com/yourusername/hello-world.git.

06

Send it up to GitHub

The first time you push, you sign in. This happens once, then your computer remembers it.

On Windows

A window pops up. Choose Sign in with your browser. Your browser opens, you sign in to GitHub, and click Authorize. Done.

On a Mac

The Terminal asks for a username and password. GitHub no longer accepts your normal password here. It needs a personal access token:

  1. In your browser, go to github.com/settings/tokens.
  2. Click Generate new token, then Generate new token (classic).
  3. Name it (like "my laptop"), set an expiry (90 days is fine), and tick the repo box.
  4. Click Generate token, then copy the long code. You only see it once.
  5. Back in the Terminal, type your GitHub username, press Enter, then paste the token as the password and press Enter.
Tip

The password stays invisible while you paste. That is normal. Just paste and press Enter. Your Mac remembers it in its Keychain afterwards.

07

Check it worked

Go back to your repository page on github.com and refresh. Click README.md. You should see the line My first change.

That is the whole loop working. You now have:

Git installed on your computer
A GitHub account
The two connected, with a real change saved and uploaded

Part 06·The bit you actually remember

The five commands you use every day

You do not need to memorise much. Almost all everyday Git use is these five, in this order.

The five everyday Git commands and what each one does
CommandWhat it does
git pullDownloads the latest version from GitHub. Do this before you start working.
git statusShows which files you have changed.
git add .Chooses all your changed files to be saved.
git commit -m "note"Saves a snapshot with a short note about the change.
git pushUploads your saved snapshots to GitHub.

Troubleshooting·When something looks wrong

Common problems, quick fixes

git: command not found

Git is not installed yet, or the window needs restarting. Close the Terminal or Git Bash window, open it again, and try git --version. If it still fails, redo the install steps for your system.

Permission denied · authentication failed

Your sign-in did not work. On Windows, run git push again and use the browser sign-in option. On a Mac, your token may have expired. Create a new one (Part 05, step 06) and try again.

fatal: not a git repository

You are in the wrong folder. Type cd hello-world (or the name of your project folder) first, then try again.

Nothing happened after a command

That is often normal. Many Git commands succeed silently. Run git status to see where things stand.

I closed the window

Your work is not gone. Everything you committed is saved on your computer, and everything you pushed is also saved on GitHub.

The password field looks frozen

Password and token input stays invisible while you type or paste. That is a security feature, not a fault. Paste, then press Enter.
