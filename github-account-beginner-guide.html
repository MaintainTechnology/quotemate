Beginner guide · Accounts and identity · About 15 minutes

Create your GitHub account, properly.

One free account, set up once, secured properly, and connected to the Git program on your computer. This guide walks every click in plain English, including the one thing that confuses everybody: Git itself has no account.

Start at Part 02 I am new here Create the account from scratch, step by step. Jump to Part 05 I have an account Just set up your name and email in Git.

Part 01·Clearing up the big confusion

Git has no account. GitHub does.

People search for "create a Git account" every day, and there is no such thing. Here is how it actually works.

Git · a program

Nothing to sign up for

Git is free software that runs on your computer, like a calculator or a notes app. You install it, you use it. No username, no password, no website, no sign-up. The closest thing Git has to an account is a name and email label it attaches to your saved work, and you set that yourself in Part 05.

GitHub · a website

One free account

GitHub is a website, so it works like any other website: you create an account with an email, a password and a username. That account is where your online copies live, and it is what you sign in to. This is the account this guide creates.

Part 02·Two minutes of prep saves ten of pain

Before you sign up, decide three things

01

Which email to use

Pick an email inbox you can open right now, because GitHub sends a code there during sign-up. A personal address is better than a work one, since you keep it if you change jobs.

02

Your username

Your username is public and appears in the address of everything you share, like github.com/yourname. It can be changed later, but links to your old name break, so it is worth choosing well the first time.

Good choices
  • +Your name or a simple variation, like sam-taylor or staylor-dev
  • +Short, lowercase, easy to say out loud
  • +Something you are happy to put on a CV
Avoid
  • -Private details like your birth year or phone number
  • -Joke names you may regret in a job interview
  • -Long strings of numbers that are hard to remember
03

A strong password

GitHub requires at least 15 characters, or at least 8 if they include a number and a lowercase letter. Longer is stronger.

  • Use a password you do not use anywhere else.
  • A short sentence works well, like four unrelated words joined together.
  • If you use a password manager, let it generate and remember one for you.

Part 03·The sign-up itself · About 5 minutes

Create the account, click by click

01

Go to github.com and click Sign up

Open your web browser, go to github.com, and click the Sign up button in the top right corner.

02

Enter your email, password and username

GitHub asks for the three things you decided in Part 02, one at a time:

  1. Type your email address.
  2. Create your password.
  3. Type your chosen username. If it is taken, GitHub tells you straight away. Try adding a word or a hyphen until you find a free one you like.
  4. If it asks about receiving product emails, answer however you like. It does not affect anything.
03

Prove you are human

GitHub shows a small puzzle to keep robots out. Solve it and continue. If you find the puzzle hard, click the audio option or the refresh option for a different one.

04

Enter the code from your email

GitHub emails you a launch code. Open your inbox, find the email from GitHub, and type the code into the sign-up page.

Tip

No email after a couple of minutes? Check your spam or junk folder. It is nearly always there.

05

Skip the questions, pick the free plan

GitHub may ask what you plan to do, how big your team is, and which tools interest you. You can answer or skip. When plans appear, choose Free. It includes everything a beginner needs, including unlimited projects.

Done

Your account exists. You are signed in and looking at your GitHub home page.

Part 04·Five minutes now, no headaches later

Lock the account with two-factor

Two-factor authentication (2FA) means signing in takes your password plus a six-digit code from your phone. If someone steals your password, they still cannot get in. GitHub strongly pushes everyone to turn it on, and one day it will insist, so do it now while you are here.

01

Get an authenticator app on your phone

Any of these free apps works: Google Authenticator, Microsoft Authenticator, or a password manager that does codes. Install one from your phone's app store.

02

Open GitHub's security settings

  1. On github.com, click your profile picture in the top right corner, then Settings.
  2. In the left menu, click Password and authentication.
  3. Click Enable two-factor authentication.
03

Scan the square code

GitHub shows a square barcode (a QR code). In your authenticator app, tap add or +, point your phone camera at the square, and the app starts showing a six-digit code that changes every 30 seconds. Type the current code into GitHub.

04

Save your recovery codes

GitHub shows a list of recovery codes. These are your way back in if you ever lose your phone. Click Download and keep the file somewhere safe that is not your phone, like a printed copy at home or your password manager.

Important

Recovery codes are shown properly once. If you skip this step and later lose your phone, you can be locked out of your account for good.

Troubleshooting·When sign-up fights back

Common problems, quick fixes

Username is taken

Someone got there first. Try adding a hyphen, a word, or your trade or town, like sam-taylor-dev. Avoid tacking on your birth year.

The launch code never arrived

Check the spam or junk folder first. Still nothing? On the sign-up page choose to resend the code, and double-check the email address you typed has no typo in it.

I forgot my password

On the sign-in page click Forgot password? and GitHub emails you a reset link. This is why the account email must be an inbox you can always open.

I lost my phone and 2FA codes

Sign in with one of the recovery codes you downloaded in Part 04, then set up 2FA again on the new phone. Each recovery code works once.

Wrong name showing on my work

Your Git identity has a typo or an old name. Re-run the two commands in Part 05 with the correct details. New snapshots use the new name.

Asked for a password in the Terminal

That prompt is not your GitHub password. Git needs a personal access token or a browser sign-in there. The setup guide, Part 05, walks through it.
