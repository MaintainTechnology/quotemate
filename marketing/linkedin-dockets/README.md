# QuoteMax split dockets, 30 posts

Thirty standalone LinkedIn posts, 1080x1350, built to one layout taken directly from the
two reference posts.

```
┌──────────────────────────────────────────┐
│  lockup                  QM-2607-NN/TAG  │  rail 150, hairline under
├───────────────────────┬──────────────────┤
│  KICKER               │                  │
│  BIG ALL-CAPS HEAD    │   tradie, full   │  split at x=540
│  body copy            │   height, hard   │
│  [ YELLOW ACTION ]    │   to the edge    │
│  terms · terms        │                  │
├───────────────────────┴──────────────────┤
│  QUOTEMAX.COM.AU              tagline    │  yellow sign-off 96
└──────────────────────────────────────────┘
```

**Why this layout and not a photo with type over it.** The tradie never has to be dimmed
to make the words legible. Each side owns its space, so the photography stays bright and
the copy stays high contrast. That is the whole point of the reference posts, and it is
what the earlier full-bleed treatments kept getting wrong.

The frame never changes. Only the left column does, taking one of five content blocks so
30 posts vary without the family breaking:

| Block | What it holds | Posts |
|---|---|---|
| `pitch` | Copy, yellow action, terms. The reference exactly. | 4, 9, 13, 18, 19, 25, 26, 28, 30 |
| `list` | Hairline rows, answer set right, like line items | 5, 7, 8, 12, 15, 16, 20, 22, 27 |
| `stat` | Three figures stacked, label under each | 1, 6, 17, 24 |
| `steps` | Numerals in bordered tiles on a spine | 3, 10, 21, 29 |
| `quote` | One line said plainly, attributed to QuoteMax | 2, 11, 14, 23 |

Twenty put the photo on the right, ten flip it. That gives a feed some rhythm without
breaking the family.

## Content

Four briefs, interleaved so no two of a kind land together: `AD` the offer cold, `PAIN`
the quoting problem, `EDU` how it works, `LEAD` ask for the enquiry or the trial. Each
post carries its reference code and brief in the rail, so a graphic maps back to this
file at a glance.

Every figure is a real product fact: under a minute, 24/7, $0 commission, $99 site visit
credited back, from $49/mo, 14-day trial on Starter Monthly, about three minutes to set
up, eight live trades, SMS and voice, Good / Better / Best. Nothing invented. No
testimonials, because there are no consented ones to quote.

## Figma

https://www.figma.com/design/5wk847w3KXLCQdWSTgCntx → **Split dockets · 30 posts**

All 30 as editable frames in one section. Photo fills carry a computed CROP transform
matching the CSS `object-position`, type is live Manrope and JetBrains Mono, colour binds
to the `QuoteMax Brand` variable collection, and the lockup is a shared component.

Other pages in the same file: **Docket set · 15 posts**, **Launch deck · 20 slides**,
**Assets**.

## Photography

All from `redesign/DesignSystem/assets/photos`: 18 new 2K frames covering electrical,
plumbing, roofing, solar, painting, carpentry, HVAC, fencing and landscaping, plus 8
older ones. Twenty one distinct photos across the 30 posts.

The tint is deliberately light, a gentle desaturation plus one warm accent pass. A brand
treatment should make a photo feel like it belongs, not hide the person in it.

Note that fencing, HVAC and landscaping appear in the photography but are **not** live
trades. They are used only on posts about the waitlist and the next intake (09, 14, 21,
27), never on a post claiming they are supported.
